# Deadline Zero — Godot 3D

This is the 3D migration lane for Deadline Zero.

## Current playable foundation
- 3D top-down / three-quarter camera.
- Keyboard + Android touch-drag movement.
- Automatic nearest-target aiming and firing.
- Four procedural enemy archetypes with escalating waves.
- Projectile impacts and emissive VFX.
- XP drops with pickup attraction.
- Level progression and three-choice upgrade overlay.
- HP/XP/run HUD.
- Mobile renderer configuration.
- Procedural industrial arena so the branch is immediately playable before external models are imported.

Open `godot/project.godot` with Godot 4.7.2 or newer and run the project.

## Art direction
The target is a polished 3D mobile survivor-shooter: large readable silhouettes, dense hordes, weapon-specific VFX, controlled camera framing, strong reward/upgrade moments and mobile-safe visual hierarchy. Zombie Waves is used only as a benchmark for those principles.

## Asset policy
See `assets/third_party/ASSET_SOURCES.md`. The preferred starting packs are Quaternius Zombie Apocalypse Kit and Sci-Fi Essentials Kit plus Poly Haven CC0 materials.
